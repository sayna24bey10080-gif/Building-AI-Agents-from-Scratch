# Agentic AI Assistant

A collection of AI agent projects built using Ollama and local LLMs.

## Features

- Local AI using Ollama
- Conversational chatbot
- Memory support
- System prompt engineering
- ReAct reasoning
- Tool calling
- Quiz generation
- Calculator
- Word counter

## Models Used

- TinyLlama
- Llama 3

## Technologies

- Python
- Ollama
- JSON
- Prompt Engineering

## Learning Journey

1. Basic LLM interaction
2. Chatbot development
3. Memory implementation
4. System agents
5. ReAct agents
6. Tool-using agents
7. SmartBuddy AI
